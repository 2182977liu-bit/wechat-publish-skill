使用说明

本工具把 Markdown 或 HTML 转成公众号兼容的内联样式 HTML，并通过剪贴板或控制台注入已登录的公众号编辑器。

  1. 写内容：粘贴 Markdown/HTML，或上传 .md / .html 文件。
  2. 选主题：极简白 / 知乎蓝 / 掘金橙 / 科技紫 / 暖木棕 / 深夜黑。
  3. 转换预览：右侧手机宽度实时预览。
  4. 注入公众号（二选一）：
    • 推荐：点「复制到剪贴板」→ 打开 mp.weixin.qq.com 新建图文 → 在编辑区 Ctrl+V。
    • 进阶：点「生成注入代码」→ Console 粘贴运行（会先检测当前登录账号再注入）。
  5. 检测账号：点「检测登录账号」后，必须切换到 mp.weixin.qq.com 后台标签页，按 F12 → Console 粘贴运行。不能贴在本地工具页（跨域读不到公众号 Cookie/页面）。系统会结合 DOM 后台界面、URL、Cookie 名综合判断；关键 token 常为 HttpOnly，JS 读不到属正常。
  6. 图片处理：正文里的外链/本地图片必须先上传到公众号素材库，再把 URL 换成 mmbiz.qpic.cn 地址，否则发布后会挂。
  7. 外链：正文超链接在公众号中经常被拦，重要链接请放到「阅读原文」。

格式不会 100% 等同于浏览器渲染，但字体、颜色、间距、引用、代码块、表格等视觉效果在公众号里会保持一致。
