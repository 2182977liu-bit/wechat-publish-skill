# 公众号注入工具：一分钟看懂这个项目

> 把本地 Markdown / HTML 转成微信公众号兼容排版，再注入已登录的编辑器，实现「格式基本不变」的发布。

## 这是做什么的？

你手里可能有很多 AI 生成的 `.md` 或网页 `.html`。直接贴进公众号，样式经常被清洗、图挂掉、外链失效。

本工具解决三件事：

1. **转换**：MD / HTML → 只含内联样式的公众号友好 HTML
2. **预览**：手机宽度看最终效果，自动提示图片/外链风险
3. **注入**：复制粘贴或 Console 脚本，写入已登录的公众号图文编辑器

## 为什么公众号不能直接贴完整 HTML？

| 限制 | 说明 |
|------|------|
| 外部 CSS 被剥离 | `<style>`、class 选择器基本失效 |
| 只保留内联 style | 视觉效果靠元素上的 `style="..."` |
| 外链图会挂 | 必须先传到素材库，换成 `mmbiz.qpic.cn` |
| 正文超链接常被拦 | 重要链接建议放「阅读原文」 |

所以行业做法不是「原样嵌 HTML」，而是**降级转换**。你在公众号里看到的精致排版，底层就是这样。

## 使用流程

```text
写好 MD / HTML
    ↓
打开 index.html（本地浏览器，无需服务器）
    ↓
选主题 → 转换预览
    ↓
方式 A：复制到剪贴板 → 公众号编辑器 Ctrl+V
方式 B：生成注入代码 → mp.weixin.qq.com 按 F12 → Console 粘贴
    ↓
预览确认 → 发布
```

## 两种注入方式怎么选？

- **复制粘贴**：最稳，日常单篇用这个
- **Console 注入**：适合批量；脚本会**先检测当前登录的公众号账号**，再尝试写入编辑器

### 能否检测当前登录账号？

**可以，但只能在公众号后台页面上做。**

- 本地工具页（`file://`）因为浏览器跨域，**读不到** `mp.weixin.qq.com` 的 Cookie
- 在公众号后台打开 F12 Console，粘贴本工具的「检测登录账号」代码，可以读到：
  - 页面昵称（DOM）
  - `slave_user` / `data_bizuin` 等 Cookie 字段
  - 是否存在 `token`（登录态）
- 「生成注入代码」同样会先检测账号，再注入；未登录会直接提示并停止

## 目录里有什么？

| 路径 | 作用 |
|------|------|
| `index.html` | 主工具入口，浏览器打开即可用 |
| `js/markdown.js` | Markdown 解析 |
| `js/themes.js` | 6 套公众号主题（内联样式） |
| `js/converter.js` | MD / HTML → 公众号 HTML |
| `js/clipboard.js` | 富文本复制 + 账号检测 + 注入片段 |
| `examples/` | 示例稿与转换结果 |
| `skill/` | AI 写公众号文时的格式规范 |
| `tests/` | 单元测试（Node 可跑） |

## 六套主题

- 极简白 — 干净留白，长文阅读
- 知乎蓝 — 知识感，适合干货
- 掘金橙 — 技术笔记
- 科技紫 — 深色科技感
- 暖木棕 — 生活 / 品牌故事
- 深夜黑 — 夜间护眼

全部只使用公众号白名单标签 + 内联样式。

## 图片必须注意

转换后工具会列出所有图片：

1. 上传到公众号「素材管理」
2. 把 HTML 里的地址换成 `https://mmbiz.qpic.cn/...`
3. 再粘贴 / 注入，否则发布后图裂

## 和 AI 的配合

已附带 Skill（`skill/SKILL.md`，安装在 `~/.claude/skills/wechat-content/`）。

让 AI 写稿时遵守：标题不超 H4、少外链、图片用可替换 URL、不写脚注/任务列表等公众号不友好语法。

## 一句话总结

**本地把排版「翻译」成公众号听得懂的内联 HTML，再安全地塞进你已登录的后台；账号信息只在公众号域名下的 Console 里检测。**
