公众号注入工具：一分钟看懂这个项目

把本地 Markdown / HTML 转成微信公众号兼容排版，再注入已登录的编辑器，实现「格式基本不变」的发布。

这是做什么的？

你手里可能有很多 AI 生成的 .md 或网页 .html。 直接贴进公众号，样式经常被清洗、图挂掉、外链失效。本工具解决三件事：

  • 转换：MD / HTML → 只含内联样式的公众号友好 HTML
  • 预览：手机宽度看最终效果，自动提示图片 / 外链风险
  • 注入：复制粘贴或 Console 脚本，写入已登录的图文编辑器

为什么公众号不能直接贴完整 HTML？

限制说明
外部 CSS 被剥离<style>、class 选择器基本失效
只保留内联 style视觉效果靠元素上的 style="..."
外链图会挂必须先传素材库，换成 mmbiz.qpic.cn
正文超链接常被拦重要链接建议放「阅读原文」
行业做法不是「原样嵌 HTML」，而是降级转换。公众号里看到的精致排版，底层就是这样。

使用流程

写好 MD / HTML
    ↓
打开 index.html（本地浏览器，无需服务器）
    ↓
选主题 → 转换预览
    ↓
A：复制到剪贴板 → 公众号编辑器 Ctrl+V
B：生成注入代码 → mp.weixin.qq.com 按 F12 → Console
    ↓
预览确认 → 发布

能否检测当前登录账号？

可以，但只能在公众号后台页面上做。

  • 本地工具页（file://）因浏览器跨域，读不到公众号 Cookie
  • 在 mp.weixin.qq.com 打开 F12 Console，粘贴「检测登录账号」代码，可读昵称、Cookie、是否登录
  • 「生成注入代码」会先检测账号，再注入；未登录会提示并停止

  1. 上传到公众号「素材管理」
  2. 把 HTML 里的地址换成 https://mmbiz.qpic.cn/...
  3. 再粘贴 / 注入，否则发布后图裂

一句话总结

本地把排版「翻译」成公众号听得懂的内联 HTML，再安全地塞进你已登录的后台；账号信息只在公众号域名下的 Console 里检测。
