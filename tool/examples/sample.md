# 如何把本地文章发到微信公众号

> 本文演示 **Markdown → 公众号内联样式 HTML** 的完整转换效果。

## 为什么要内联样式？

公众号编辑器会剥离外部 CSS，只保留标签上的 `style` 属性。所以精致排版的关键是：

1. 把样式写到每个元素上
2. 只使用编辑器白名单标签
3. 图片先上传到素材库

## 支持的语法

| 语法 | 示例 | 支持 |

| 斜体 | *强调* | 是 |
| 行内代码 | `code` | 是 |
| 删除线 | ~~过时~~ | 是 |
